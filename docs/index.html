Tok DOI

atomic provenance · register cryptographic proof of any artifact
“No Added Sugar.”

Any digital artifact — a byte, a token, a sentence, a message, a chat, an image, a file — reduces to SHA-256 → OpenTimestamps → AyeSHA → registry. The raw .ots is never stored, only its AyeSHA encoding. Registries are public, append-only, and version-controlled. Each record is an atomic sub-DOI; curated sets publish as one Zenodo DOI via Misty.
