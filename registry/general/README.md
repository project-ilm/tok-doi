# General registry — records

**Append-only. Public. Version-controlled.** One JSON object per line in
`records.jsonl`, each conforming to [`SCHEMA.json`](SCHEMA.json). The raw `.ots`
is never stored — only its AyeSHA encoding. `tok` ids are `tok:general:0001`,
`tok:general:0002`, … Each record is an atomic **sub-DOI**; curated sets can be
published as one Zenodo DOI via Misty (see `../../collections/`).
